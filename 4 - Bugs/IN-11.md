## Precondiciones

1. La base de datos está disponible.
2. El usuario "operador" está activo y con 0 intentos fallidos. Se puede comprobar con:

   ```sql
   SELECT estado, intentos_fallidos FROM usuarios WHERE usuario = 'operador';
   ```

3. Si no se cumple, ejecutar:

   ```sql
   UPDATE usuarios
   SET estado = 'Activo'
   WHERE usuario = 'operador';

   UPDATE usuarios
   SET intentos_fallidos = 0
   WHERE usuario = 'operador';
   ```

4. La aplicación InventarioPro está en la pantalla de login.

## Pasos para reproducir

1. Escribir en el campo Usuario `operador`.
2. Escribir en el campo Contraseña `opera1234` y pulsar "Ingresar" 2 veces con la misma contraseña.
3. Escribir en el campo Contraseña `Opera123` y pulsar "Ingresar" por tercera vez. El sistema permite el acceso.
4. Cerrar sesión.
5. Volver a escribir el usuario `operador` y la contraseña `opera1234`, y pulsar "Ingresar".

## Resultado esperado

El login correcto del paso 3 reinicia el contador de intentos (RQ-06). En el paso 5 el sistema no permite el acceso, muestra "Usuario o contraseña incorrectos" y la cuenta **no** se bloquea, porque es el primer intento fallido después del login correcto.

## Resultado obtenido

En el paso 5 el sistema bloquea la cuenta y muestra el mensaje "Cuenta bloqueada. Contacte al administrador", lo que demuestra que el contador no se reinicia.

## Información adicional

- En la base de datos se comprueba que el contador no se reinicia, sigue aumentando. Al terminar los pasos, `intentos_fallidos` del operador es 3. Consulta usada:

  ```sql
  SELECT estado, intentos_fallidos FROM usuarios WHERE usuario = 'operador';
  ```

- Para volver a probar el bug, ejecutar las consultas de la precondición 3.
